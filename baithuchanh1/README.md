# Bài thực hành 1 – Thiết kế Web

Bài thực hành tập trung vào việc xây dựng nền tảng cơ bản về HTML và CSS, thông qua các bài luyện tập về cấu trúc trang web, các thành phần ngữ nghĩa và căn chỉnh giao diện.

## 📚 Nội dung

* **Semantic Elements** — Thực hành sử dụng các phần tử ngữ nghĩa trong HTML để xây dựng cấu trúc trang web.
* **Thanh điều hướng (Nav)** — Tạo và định dạng thanh điều hướng bằng HTML và CSS.
* **Nội dung trang** — Xây dựng nội dung chính và kết hợp các thành phần để tạo thành một trang web cơ bản.
* **Bảng (Table)** — Thực hành tạo và định dạng bảng bằng HTML.
* **Căn chỉnh bằng CSS** — Luyện tập căn chỉnh vị trí, khoảng cách và bố cục các phần tử trên trang.

## 🎯 Mục tiêu

Làm quen và thành thạo hơn với HTML, các yếu tố ngữ nghĩa, CSS cơ bản, bố cục trang web và kỹ thuật căn chỉnh, thông qua các bài tập nhỏ và việc xây dựng một trang web đơn giản.

## ⭐ Đánh giá độ khó

Mức độ: **Dễ**. Kiến thức sử dụng chủ yếu là HTML/CSS cơ bản, không có gì quá phức tạp, làm khá thoải mái.

## 📈 Mức độ ôn luyện

Ôn lại tốt phần semantic elements, cấu trúc bảng và cách dùng Flexbox để căn chỉnh (thanh nav, footer). Cần luyện thêm về layout nâng cao và responsive.
